# 🤖 AI Study Buddy

AI Study Buddy is an AI-powered learning platform designed to help students study smarter, stay organized, and improve their academic performance through personalized learning tools.

## 🚀 Features

* 🔐 **Login & Registration** – Secure student authentication
* 👤 **Student Profile** – Manage personal information, course, semester, goals, and subjects
* 🤖 **AI Study Planner** – Create personalized study plans based on subjects, goals, and exam dates
* 💬 **AI Buddy Chatbot** – Get learning assistance and explanations
* 📝 **AI Quiz** – Practice MCQ quizzes with different subjects and difficulty levels
* 📚 **Smart Notes** – Create, manage, and summarize study notes
* 📊 **Progress & Analytics** – Track study hours, quiz performance, progress, and streaks
* 📱 **Responsive UI** – Student-friendly interface for different screen sizes

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/suhaniaggarwal102-code/AI-Study-buddy-.git
```

### 2. Open the project

```bash
cd AI-Study-buddy-
```

### 3. Install frontend dependencies

```bash
cd frontend
npm install
```

### 4. Run Angular frontend

```bash
ng serve
```

Open:

```text
http://localhost:4200
```

### 5. Install backend dependencies

Open another terminal:

```bash
cd backend
npm install
```

### 6. Start the backend

```bash
node server.js
```

The backend runs on the configured server port.
